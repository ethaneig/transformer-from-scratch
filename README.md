Implementation of a transformer from scratch (without AI). Built in June 2026, finally got around to putting it up here now.

To set up venv:
```
uv sync
```

To train tokenizer:
```
uv run train-tokenizer
```

To train transformer:
```
uv run train-transformer
```

To run transformer: 
```
uv run generate
```
